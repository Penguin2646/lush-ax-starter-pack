## MODE 1: FC 분산 분석 (Forecast Variance Analysis)

### 목적
예측(FC) 대비 실제 판매 오차를 구조적으로 분석.

### 단계

**Step 1 — 데이터 수신**
- 파일 경로가 있으면 `excel-to-csv` 스킬로 변환 후 읽기
- 직접 붙여넣기면 마크다운 테이블로 파싱

**Step 2 — 오차 계산**
```
오차율 = (실적 - FC) / FC × 100
```
- 양수: 초과 달성 (Over)
- 음수: 미달성 (Under)
- ±20% 기준 분류 (product-forecast 기준 유지)

**Step 3 — 분산 분류 (materiality 필터)**

| 구분 | 기준 | 액션 |
|------|------|------|
| 정상 범위 | ±20% 이내 | 자동 적용 |
| 검토 필요 | ±20% ~ ±50% | 원인 분석 |
| 이상 신호 | ±50% 초과 | 우선 검토 |

**Step 4 — 원인 분류 프레임워크**
오차 발생 시 아래 4가지 원인 중 해당 여부 확인:
1. **수요 변동**: 시즌성, 이벤트, 트렌드 변화
2. **공급 이슈**: 재고 부족, 납기 지연
3. **가격/프로모션**: 할인, 번들, 경쟁사 가격 변동
4. **외부 요인**: 채널 변화, 신제품 출시 영향

**Step 5 — 출력**
- 제품별 FC/실적/오차율 테이블
- 초과/미달 TOP 5 제품
- 원인 분류 요약
- 다음 FC 조정 권고사항

## MODE 2: 판매 예측 (Sales Forecasting)

### 목적
과거 판매 데이터 기반으로 다음 기간 수요를 예측.

### 예측 방법 (데이터 기간에 따라 자동 선택)

**방법 A — 가중 이동평균 (3개월 이상 데이터)**
```
WMA = (최근월 × 0.5) + (전전월 × 0.3) + (3개월전 × 0.2)
```
- 최근 트렌드에 더 높은 가중치

**방법 B — YoY 성장률 적용 (전년 동월 데이터 있을 때)**
```
예측 = 전년 동월 × (1 + YoY 성장률)
YoY 성장률 = (올해 누적 - 작년 누적) / 작년 누적
```

**방법 C — 시즌 지수 조정 (12개월 이상 데이터)**
```
시즌 지수 = 월별 판매량 / 연간 월평균
예측 = 기준 트렌드 × 해당월 시즌 지수
```

**방법 D — 단순 추세 (데이터 부족 시)**
```
예측 = 최근 3개월 평균 × 트렌드 계수
트렌드 계수 = 최근 3개월 평균 / 그 이전 3개월 평균
```

### 예측 신뢰도 표시
- **높음**: 12개월+ 데이터, 계절성 패턴 명확
- **중간**: 6~12개월 데이터
- **낮음**: 6개월 미만, 신규 제품

### 전제 조건 명시 (필수)
예측 결과와 함께 반드시 기술:
- 사용한 예측 방법
- 가정한 시장 조건 (이벤트 없음/있음, 재고 정상 등)
- 불확실 요인

## MODE 3: 리포트·요약 생성 (Report Generation)

### 목적
분석 결과를 커뮤니케이션 가능한 형태로 정리.

### 리포트 구조 템플릿

```markdown
## [기간] 판매 성과 요약

### 핵심 지표
- 총 판매량: X개 (FC 대비 +N% / -N%)
- 매출: XXX원 (MoM +N%, YoY +N%)
- FC 달성률: N%

### TOP 퍼포머
| 제품 | 판매량 | FC 달성률 |
|------|--------|----------|

### 주목 포인트
1. [초과 달성 요인]
2. [미달성 요인]
3. [다음 기간 주의 사항]

### 다음 기간 전략 권고
- [구체적 액션 1]
- [구체적 액션 2]
```

### 출력 형식 선택
사용자가 명시하지 않으면 확인:
- **마크다운**: Daily Note 또는 위키 저장용
- **테이블**: 회의 자료용
- **HTML**: 이메일/배포용 (`md-to-pdf` 스킬 연계)

## MODE 4: 데이터 전처리

엑셀/CSV 데이터 정리는 기존 스킬에 위임:

```
Excel 파일 → excel-to-csv 스킬 → csv-clean 스킬 → sales-analysis 분석
```

자주 쓰는 패턴:
```bash

# 소계 제거 + 숫자 정리

```

## 분석 품질 원칙

1. **전제 명시**: 모든 예측/분석에 가정 조건 기술
2. **불확실성 표현**: 단일 수치보다 범위 (예: 1,200~1,400개)
3. **실행 가능한 결론**: 인사이트가 아닌 다음 액션으로 마무리
4. **K-PLU 처리**: product-forecast 기준 따름 (K로 시작하는 PLU 별도 표시)
